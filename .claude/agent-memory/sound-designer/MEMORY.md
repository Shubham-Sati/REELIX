# sound-designer memory
Lessons from earlier videos. Add 1-3 short, specific lessons after each video; keep this file under 60 lines (merge or drop old ones).

- Video 1 had no sound effects at all; reviewers found it flat. Whooshes on cuts and one hit on the reveal are the minimum.
- Read word times in captions.json before placing loud effects; put hits/impacts in the pause before a stressed word, not on it.
- Ambience files (fire, crowd, wind) are ~3 s long: one per scene, starts more than 0.2 s from any whoosh or hit. 10 effects in a 25 s short was not cluttered (reviewer: SFX stayed under the voice).
