# storyboard-artist: FLUX prompts

- FLUX schnell has no negative prompt: "no beard" / "no ribbon" puts the word in and can ADD it (v3: both Montgolfier brothers came out bearded). Describe what you want instead: "smooth clean-shaven chin and bare upper lip", "plain long-sleeved linen chemise with a smooth front". 18th-century French men were clean-shaven.
- Character drift: the same character came out younger and slimmer in one shot. Repeat age, build, hair colour and clothes word-for-word in every prompt; put them in the character description itself, since that text is appended to every prompt.
- Style drifted photoreal with imageStyle only at the end; open every prompt with "Painterly 2D illustration, not a photograph".
- Vertical frames: say "fully visible, centred, space above and below" or tall objects get cut at the top.
- Groups of animals: name each animal with its colour and say "all inside the basket"; small extra animals melt into each other.
- Hero objects whose modern version dominates (Montgolfier balloon -> modern striped basket balloon in every shot, even after redo): plan the shot as engine 'custom' (3D) from the start.
