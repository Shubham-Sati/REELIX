# storyboard-artist memory
Lessons from earlier videos. Add 1-3 short, specific lessons after each video; keep this file under 60 lines (merge or drop old ones).

- FLUX misreads period objects. Say what an object is NOT: "no ribbon, no gift wrap", "long-sleeved linen chemise, no buttons, no pocket".
- Character drift: the same character came out younger and slimmer in one shot. Repeat age, build, hair colour and clothes word-for-word in every prompt.
- Groups of animals: name each animal with its colour and say "all inside the basket"; small extra animals melt into each other.
- Vertical frames: say "fully visible, centred, space above and below" or tall objects get cut at the top.
- Negatives did not save the Montgolfier balloon: FLUX drew a modern striped basket balloon in every balloon shot, even after redo. For a hero object whose modern version dominates, plan the shot as engine 'custom' (3D) from the start.
- Order shots by when their key word is spoken: in video 2 the laundry and Joseph shots were in script order but each ~2.5 s off the voice.
- Style drifted photoreal with imageStyle only at the end; open every prompt with "Painterly 2D illustration, not a photograph".
