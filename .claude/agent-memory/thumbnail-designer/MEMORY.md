# thumbnail-designer memory
Lessons from earlier videos. Add 1-3 short, specific lessons after each video; keep this file under 60 lines (merge or drop old ones).

- A short needs a vertical 9:16 thumbnail; the first one asked for 16:9 by mistake. Check brief.format first.
- No creator photo exists: make the object/scene the focal subject (e.g. glowing balloon), no people, lower third empty for the headline.
- Pull the headline from script.json's closing line or twist (e.g. "WRONG IDEA, IT FLEW"); keep it at 4 words or fewer.
