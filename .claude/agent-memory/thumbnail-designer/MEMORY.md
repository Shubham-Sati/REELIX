# thumbnail-designer memory
Lessons from earlier videos. Add 1-3 short, specific lessons after each video; keep this file under 60 lines (merge or drop old ones).

- A short needs a vertical 9:16 thumbnail; the first one asked for 16:9 by mistake. Check brief.format first.
- No creator photo exists: make the object/scene the focal subject (e.g. glowing balloon), no people, lower third empty for the headline.
- Pull the headline from script.json's closing line or twist (e.g. "WRONG IDEA, IT FLEW"); keep it at 4 words or fewer.
- 3D look (pictures false): use { frame, headline }. The opening hero shot (~1.5s) works well, but the burned-in captions and scene label show in the still, so pick a frame where they are small or absent.
- Space-object shorts (Venera 7): frame 1.5s hero (lander + planet) beats 0.6s; the caption sits at ~y1400 over the planet, the scene label near the top, so the subject stays mid-frame.
- Toy3d diorama shorts: the frame where the key change is finished (e.g. salt slab at ~3s) beats the opening; the headline can be a twist phrase not in the captions.
- Explainer toy3d (rock salt, 10 min): frame 6s (finished salt slab in a frame) beat 3s map and 12s column; every frame has a scene label + big caption, so choose the one with the cleanest subject.
